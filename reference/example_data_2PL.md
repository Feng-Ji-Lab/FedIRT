# Binary Response Dataset for Federated 2PL Model

A synthetic dataset composed of responses from 160 students to 10 items,
with all responses binary.

## Usage

``` r
example_data_2PL
```

## Format

A dataframe with 160 rows and 10 columns. Each row corresponds to a
student's set of responses, and each column represents the responses of
all students to a particular item.

## Source

The data are synthetically generated.

## Details

A response of 1 indicates a correct answer, and 0 represents an
incorrect answer.

## Examples

``` r
data(example_data_2PL)
```
